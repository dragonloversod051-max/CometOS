# CometOS

### Main Description
This is a WebOS designed for a fictional character- Comet of the continent of Alarica.

### Current Progress
It's still currently incomplete. 
The main desktop screen and top + bottom bar is done, along with one app:
  
#### The notebook app:
Has an editable space to store your thoughts. Has an autosave feature so you don't lose your work.
    

### Working on:
A family tree app to provide some insight into the past of Alarica. Amazing for lore-enthusiasts.
